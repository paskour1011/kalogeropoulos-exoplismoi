# Καλογερόπουλος Εξοπλισμοί Ι.Κ.Ε. — Ιστότοπος

React 18 + Vite + Tailwind CSS + Lucide Icons.

## Εκκίνηση

Χρειάζεστε [Node.js](https://nodejs.org) 18 ή νεότερο. Μέσα σε αυτόν τον φάκελο (Τερματικό ή VS Code → Terminal):

```bash
npm install
npm run dev
```

Ανοίξτε το http://localhost:5173. Για να το δείτε από το κινητό σας στο ίδιο Wi‑Fi: `npm run dev -- --host`
και ανοίξτε στο κινητό τη διεύθυνση «Network» που εμφανίζεται.

## Δημοσίευση

`npm run build` → ανεβάστε τα περιεχόμενα του φακέλου `dist/` σε οποιονδήποτε πάροχο φιλοξενίας.

## Πού αλλάζω τι

| Θέλω να αλλάξω | Πού |
| --- | --- |
| Τηλέφωνο, fax, διεύθυνση | `src/App.jsx` → `BIZ` |
| Κατηγορίες και είδη καταλόγου | `src/App.jsx` → `CATEGORIES` |
| Φωτογραφίες καταστήματος | `src/App.jsx` → `GALLERY` και `src/img/` |
| Χρώματα | `src/index.css` → `--green`, `--kraft-soft` κ.λπ. |
| Τίτλος και περιγραφή για Google | `index.html` |

Κάθε φωτογραφία υπάρχει σε δύο μεγέθη (`-480.webp` για κινητά, `-960.webp` για υπολογιστές).
Αν αλλάξετε μια φωτογραφία, φτιάξτε και τα δύο.

Το `src/artifact-entry.jsx` χρησιμοποιείται μόνο για την προεπισκόπηση στο Claude. Μπορείτε να το αγνοήσετε.
